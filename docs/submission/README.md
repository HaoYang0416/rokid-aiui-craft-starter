# 回声 Echo 提审材料草案

## 一句话介绍

说一句“回声”，把刚刚一分钟变成一张带画面、声音和 AI 摘要的记忆卡片。

## 权限用途

- **麦克风**：用户主动开启后，在内存中维护最近一分钟声音缓冲；未触发内容不保存。
- **相机**：仅在用户触发“回声”时拍摄一张第一视角照片。
- **网络**：把用户主动触发的照片和音频发送到 Echo 服务，完成保存、转写和摘要。

## 隐私说明要点

- 应用启动后不会自动录音，必须由用户主动开启。
- 循环缓冲只存在于运行内存，不写入本地文件、不自动上传。
- 用户停止、退出或页面进入后台时，未触发缓冲立即清空。
- 仅用户主动触发的片段会保存和处理。
- 正式版本必须提供历史记录删除入口和服务端数据保留期限。

## 审核演示路径

1. 打开应用，展示“尚未开启”。
2. 点击“开启回声”，展示缓冲计时。
3. 说“Rokid，回声”。
4. 展示拍照、处理和保存状态。
5. 展示包含触发画面、时间和 AI 摘要的记忆卡片。
6. 再次开启后点击“停止并清除”，演示隐私行为。

## 当前审核备注

- 本版本是黑客松 demo，语音唤醒事件暂时等同于“回声”指令。
- 应用只支持前台回溯，不宣称系统级后台常驻。
- 服务端 API Key 不包含在眼镜应用或打包产物中。
