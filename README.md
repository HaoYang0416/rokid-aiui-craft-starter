# Rokid AIUI Craft Starter

面向 Rokid 智能眼镜黑客松的 AIUI 应用开发仓库。项目将以 Rokid Craft 为主要工作台，覆盖应用模拟、设备联调、打包与提审。

> 当前仓库是技术栈中立的初始化骨架。请先在 Rokid Craft 中确认活动指定的 AIUI 模板与 SDK 版本，再把官方生成的工程文件合入 `src/`；不要凭经验手写可能已过期的清单或打包配置。

## 项目目标

- 快速验证适合眼镜端的 AI 交互体验
- 在 Rokid Craft 中完成模拟与设备测试
- 留存可复现的构建、打包和提审材料
- 避免把密钥、个人数据和本地产物提交到 GitHub

## 目录结构

```text
.
├─ assets/              # 图标、图片、音频等应用资源
├─ craft/               # Craft 配置示例与操作记录（不提交打包产物）
├─ docs/                # 产品、交互、测试和提审文档
│  └─ submission/       # 商店文案、截图清单、隐私说明等
├─ src/                 # AIUI 应用源码；从活动指定模板开始
├─ .env.example         # 环境变量名称示例，不含真实密钥
├─ .gitignore
└─ README.md
```

## 开始开发

1. 在 Rokid Craft 中选择黑客松指定的 AIUI 应用模板与 SDK 版本。
2. 将模板工程导入本仓库，并保留官方要求的目录和清单文件名称。
3. 在 `src/` 开发应用，在 `assets/` 管理资源，在 `docs/` 记录交互与测试。
4. 将 `.env.example` 复制为 `.env.local`，只在本机填入服务地址或密钥。
5. 使用 Craft 模拟器验证核心流程，再进行真机测试。
6. 打包前完成下方检查，并将截图、文案和隐私说明整理到 `docs/submission/`。

## Craft 工作流检查表

### 模拟

- [ ] 首次启动、返回与退出路径正常
- [ ] 语音、触控或其他输入均有清晰反馈
- [ ] 弱网、超时、权限拒绝和空结果有兜底提示
- [ ] 字号、对比度、信息密度适合眼镜端阅读

### 打包

- [ ] 应用 ID、名称、版本号和图标已确认
- [ ] 使用活动要求的 SDK 与构建配置
- [ ] 生产环境不包含测试密钥、调试日志或个人数据
- [ ] 打包产物已在目标设备完成一次安装验证

### 提审

- [ ] 应用简介、功能说明和操作指引完整
- [ ] 截图与演示材料来自当前提交版本
- [ ] 权限用途与隐私说明准确
- [ ] 已记录已知限制、测试账号和审核备注（如需要）

## 分支与提交建议

- `main` 始终保留可演示、可打包状态。
- 功能分支使用 `feat/<name>`，修复分支使用 `fix/<name>`。
- 每次准备 Craft 打包时创建版本标签，例如 `v0.1.0`。

## 安全说明

真实 API Key、访问令牌、签名文件、设备数据及 Craft 本地缓存不得提交。若密钥曾进入 Git 历史，请立即在服务端撤销并重新生成。
